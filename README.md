# My HQ

## How to run

You need Node.js 20+ and [pnpm](https://pnpm.io).

```bash
pnpm install
pnpm hq
```

HQ opens in your browser at `http://127.0.0.1:7420`. If it doesn't open, use the link printed in the terminal (it includes a token that changes on every start).

To stop it, press `Ctrl+C` in the terminal.
